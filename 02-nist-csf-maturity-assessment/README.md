# NIST CSF Cybersecurity Assessment and Three-Year Roadmap

## Project Overview

This project involved a comprehensive, scenario-based cybersecurity control assessment of Oscorp, a simulated enterprise, as part of the GRC Mastery professional training programme.

The objective was to identify deficiencies in the organization's existing cybersecurity controls and develop a risk-based, three-year cybersecurity improvement programme aligned with the NIST Cybersecurity Framework.

| Project Information | Details |
|---|---|
| Organization | Oscorp (Simulated Enterprise) |
| Framework | NIST CSF 1.1-style assessment |
| Assessment Type | Desk-based, evidence-limited assessment |
| Controls Assessed | 98 |
| Improvement Initiatives | 18 |
| Planning Horizon | 3 Years |
| Training Provider | GRC Mastery |

## Business Problem

Oscorp relies heavily on cloud infrastructure and SaaS applications to support its business operations.

Although the organization has established several technical and physical security controls, it lacks a formal cybersecurity strategy, defined security accountability and comprehensive cybersecurity risk management processes.

Management requires a structured cybersecurity programme that addresses existing control deficiencies, prioritizes security investments and strengthens organizational resilience over three years.

## Project Objectives

- Assess the organization's existing cybersecurity controls.
- Identify security deficiencies and evidence gaps.
- Prioritize cybersecurity risks and remediation activities.
- Develop a comprehensive three-year cybersecurity roadmap.
- Define proposed accountable owners, implementation timelines and success measures.
- Preserve and strengthen existing effective security controls.

## Assessment Methodology

The assessment was structured around the five NIST CSF functions:

- **Identify:** Asset management, governance and cybersecurity risk.
- **Protect:** Access management, data protection and protective technologies.
- **Detect:** Security monitoring and event detection.
- **Respond:** Incident response, communications and mitigation.
- **Recover:** Recovery planning and organizational resilience.

Each control was evaluated against the supplied organizational current-state information and assigned one of four assessment outcomes:

| Status | Assessment Criteria |
|---|---|
| Pass | Control explicitly supported by the supplied information. |
| Partial | Some supporting controls exist, but coverage is incomplete. |
| Fail | An explicit control deficiency was identified. |
| Not Evidenced | Insufficient information to establish control status. |

Control-specific observations and remediation recommendations were documented in the assessment workbook.

## Key Findings

| Priority | Risk Area | Identified Deficiency |
|---|---|---|
| Critical | Cybersecurity Governance | No formal cybersecurity strategy, defined accountability or cyber risk management process. |
| Critical | Identity and Access Management | No MFA or PAM; shared privileged administrator credentials. |
| Critical | Vulnerability Management | Ad hoc vulnerability scanning and a significant backlog of high and severe vulnerabilities. |
| High | Detection and Response | No SIEM or formal cybersecurity detection and response capability. |
| High | Data Protection | Absence of DLP and information classification policies. |
| High | Third-Party Risk | No formal supplier cybersecurity risk assessment process. |

## Existing Security Strengths

The assessment identified several existing controls that should be retained and strengthened:

- Regular backups and disaster recovery testing.
- Documented business continuity plans.
- Next-generation firewalls and network segmentation.
- Physical security monitoring and employee vetting.
- Secure operating environment for employee laptops.

## Three-Year Cybersecurity Roadmap

### Year 1 — Establish Foundations and Address Critical Risks

Nine initiatives focused on immediate security exposures and foundational governance:

- Cybersecurity governance and risk management.
- Identity and privileged access security.
- Vulnerability management and endpoint hygiene.
- Incident response readiness.
- Data inventory and protection.
- Third-party security assurance.
- Security monitoring.
- Security awareness and access lifecycle management.
- Business continuity and supplier recovery alignment.

### Year 2 — Strengthen and Integrate Security Controls

Five initiatives focused on institutionalizing cybersecurity processes:

- Privileged access management and conditional access.
- Detection engineering and incident response.
- Cloud and information governance.
- Continuous supplier security monitoring.
- Enterprise risk and compliance integration.

### Year 3 — Assurance, Optimization and Resilience

Four initiatives focused on evaluating control effectiveness and continuous improvement:

- Independent cybersecurity assurance.
- Security optimization and automation.
- Enterprise cybersecurity exercises and resilience testing.
- Cybersecurity strategy refresh and maturity review.

Each initiative includes a proposed implementation timeline, priority, accountable owner, success measure and NIST CSF alignment.

## Project Attribution and Limitations

This project was developed as part of a scenario-based practical assessment undertaken through GRC Mastery.

The original business scenario and assessment framework were supplied by the training provider. The portfolio assessment and roadmap were developed with AI-assisted analysis and documentation.

The assessment was based on supplied current-state information. No independent control testing, interviews or verification of control effectiveness were performed.

Proposed implementation timelines, accountable owners and success measures represent recommendations rather than existing organizational arrangements or completed implementations.

The assessment follows the NIST CSF 1.1-style structure supplied in the training materials. No formal maturity score is inferred.

This project does not represent an actual client engagement, independent certification audit or implemented cybersecurity programme.
